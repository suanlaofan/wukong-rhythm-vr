# 悟空节奏 1.1.0

2026-09-07。承接 0.2.0 整改与本轮用户的实际试玩反馈。

## 修改

- 21 首音乐共 4,509 个算法拍点、3,742 个音符；出球提前四拍、预警提前两拍，使用同一可变拍点时间表。Perfect ±70 ms / Good ±140 ms。
- 小预警圈采用 0.28m 基准与 1.32 最大缩放。石球普通 / 强化碰撞半径 0.58m / 0.72m，附加 0.16m 接触容差。棒身及两端扫掠，防重复评分。
- 恢复短打击音效，独立音频通道预载；金箍棒跟随鼠标或右手柄。棒放大 25% 并保持握点。
- 每次投掷使用新动作 ID；目标在有限飞行时间内保留，出手或接触踩拍可得分。偏拍投掷仍碎石但记 Miss。
- 右侧 HUD 正对玩家、相对高度上移 12cm；移除大型底部操作卡片和重复说明，仅保留顶部轻量提示。
- 模拟器的佩戴传感器持续返回 false，曾导致游戏首帧暂停且无法恢复。仅在 `ro.kernel.qemu=1` 的模拟器忽略物理佩戴值，保留应用失焦处理；实体头显仍使用原摘戴与追踪保护。
- 模拟器支持 XR 按键及 Android Gamepad 回退。按实际默认映射显示 I/K、空格、Delete、X、J/L，避免把手柄字母 A 当成电脑键盘 A。
- 复用游戏此前制作的金色节奏徽章，配置默认、Android Legacy / Round / Adaptive 图标。原图不变，自适应前景仅增加平台安全边距；构建时检查图标存在且导入为 Texture2D。
- 版本 1.1.0，versionCode 3，ARM64，非 Development 构建。

## 验证

- 新构建的规则检查：7,586 项通过，包括时间边界、帧间扫掠、重复消费、全曲库容量与时间表，以及模拟器佩戴处理和单行提示。
- PICO 0.13 模拟器实际按键触发 `SongSelect → CountIn → Playing`，持续播放到 `Results`。暂停 / 四拍继续 / 长按返回选曲均有实际状态日志和画面。
- 模拟器音频出口采样 3 秒，存在非零音乐输出；该检查不能证明真机扬声器、蓝牙延迟或逐曲听感准确性。
- 用户已确认本轮模拟器试玩可以继续发布。
- 构建、Android 数字签名、16KB ZIP 对齐及 APK 内图标资源分别检查。ZIP 对齐不能单独证明所有设备兼容性。

## 尚待真机验收

Swan 的登记应用身份、平台签名拒绝原因、持续帧率、真实控制器快速运动以及音频延迟仍需设备复验。当前 GitHub 包沿用历史测试身份与 Android Debug 证书，不冒充完成 PICO 商店的正式签名验收。48 石块与 16 粒子池等优化已实现，但不宣称真机帧率提升到某个数值。

## 素材与接口

图标来源为本游戏原有 `icon_rhythm_talisman` 素材；当前资产检索工具不可用，未引入外部替代图。Android 平台槽位通过 [Unity PlayerSettings.SetPlatformIcons](https://docs.unity3d.com/cn/6000.0/ScriptReference/PlayerSettings.SetPlatformIcons.html) 写入。
